> **This is a personal fork of [CrossInk](https://github.com/uxjulia/CrossInk)**, which itself is based on [CrossPoint Reader](https://github.com/crosspoint-reader/crosspoint-reader).
>
> This fork focuses on a few personal workflow and UI changes while keeping the existing CrossInk features. The main addition is bringing the **Sticky Notes** feature from CrossInk's Seeed Studio Sticky build to the Xteink X3/X4, allowing notes to be received wirelessly and displayed as a persistent sleep-screen note.
>
> **Sticky Notes support is still under development.** For now, notes can only be received through **ESP-NOW**.

### Supported Devices

- Xteink X3
- Xteink X4

## What's different in this fork

My goal with this fork is to preserve the core CrossInk reading experience while adding a small productivity feature: **Sticky Notes**.

### Highlights

- Added **Sticky Notes** support to Xteink X3/X4.
- Sticky Notes can be received wirelessly using **ESP-NOW** and saved as the device's sleep-screen note.
- Sticky Notes is still under development and currently supports **ESP-NOW input only**.
- On the `Minimal` / `Dashboard` home layout, Sticky Notes can be accessed directly from the front-button shortcuts, while file browsing remains available from the Menu.
